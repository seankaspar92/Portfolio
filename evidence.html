PORTFOLIO GOVERNANCE

Evidence policy

The portfolio separates verified implementation, simulated validation, active development, and illustrative concept art so a visual does not become a claim by accident.

Public-claim rules

Implemented capability

Claim only when supported by code, tests, documentation, working artifacts, or directly observed operating use.

Simulated results

Allowed only when explicitly labeled as simulation or test evidence. Never convert validation into real customer or financial impact.

Performance metrics

Publish only when reproduced from a defined dataset, methodology, and run output.

Time saved / improvement

Publish only when a before/after baseline is measured. Generated infographic percentages are never evidence.

Sensitive data

GOTS and career evidence use sanitized examples only. Personal medical, financial, family, account, or other sensitive records stay private.

AI-assisted development

Describe implementation accurately as AI-assisted where appropriate rather than implying every line was manually authored.
