PORTFOLIO GOVERNANCE · v2.1

Evidence policy

The portfolio separates verified implementation, simulated validation, lifecycle state, active development, and illustrative material so a visual, test result, or roadmap item does not become a capability claim by accident.

Public-claim rules

Implemented capability

Claim only when supported by code, tests, documentation, working artifacts, or directly observed operating use.

Simulated results

Allowed only when explicitly labeled as simulation or test evidence. Never convert validation into real customer, mission, production, or financial impact.

Performance metrics

Publish only when reproduced from a defined dataset, methodology, and retained run output.

Time saved / improvement

Publish only when a before/after baseline is measured. Generated infographic percentages are never evidence.

Sensitive data

GOTS, career, HOPS, and other public examples use sanitized or synthetic material where required. Personal medical, financial, family, account, operationally sensitive, or other private records stay private.

AI-assisted development

Describe implementation accurately as AI-assisted where appropriate rather than implying every line was manually authored.

MATURITY BOUNDARIES

Lifecycle status is part of the evidence

HOPS

HOPS is presented only as an independently developed synthetic portfolio prototype. Retained v2.6 evidence supports the bounded release-candidate controls, including 92/92 automated tests, 44/44 release-security invariants, 50/50 Chromium QA assertions, zero console/page errors, and visual-QA pass. The evidence does not claim operational deployment, employer ownership, government approval, production authorization, real-world mission performance, or third-party adoption.

MLB EDGE

v0.2.2 is the locally validated baseline. v0.3.0 remains a Candidate until its authentic local Statcast data-foundation gate passes. Candidate architecture and package tests are not presented as validated predictive performance.

NFL EDGE

Connected dashboard, research-firewall, provenance, price-integrity, replay, and kickoff-time controls are described as validated where repository evidence supports them. Historical provenance infrastructure is not represented as live-prediction integration unless that connection is actually implemented and verified.

AI Operating System

AIOS v1.0.0 / Phase 24 remains the stable runtime release contract. Phase 25 Context Mode is represented only as post-v1 developer-context tooling and does not expand production runtime claims.

AI Skills

The public governed-capability count includes Active and Testing skills only. Planned external candidates remain excluded until internal specification, safety/tool review, and representative validation gates are satisfied.

Resume evidence

The September 12 canonical resume evidence set is synchronized across the browser resume and downloadable DOCX/PDF artifacts. Public download artifacts are cryptographically bound in the release manifest, and future resume changes must update browser, DOCX, PDF, and validation receipts together before release.

Roadmap items

Planned work, research targets, and future integrations remain roadmap evidence only. They are not counted as implemented capability until their own acceptance and validation gates are met.
