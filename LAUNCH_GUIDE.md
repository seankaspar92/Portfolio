# Portfolio v1.7 Launch Guide

## Recommended first deployment: GitHub Pages

This build is static HTML/CSS/JS and is ready for GitHub Pages.

### Publish flow
1. Create a new public repository, recommended name: `portfolio`.
2. Upload the contents of this folder to the repository root.
3. In GitHub: **Settings → Pages**.
4. Set **Source** to `Deploy from a branch`.
5. Select branch `main` and folder `/ (root)`.
6. Save.
7. GitHub will provide the live portfolio URL.

## Before announcing publicly
- Replace `YOUR-DOMAIN.example` in `robots.txt` and `sitemap.xml` with the final live URL.
- Open all 7 primary pages on desktop and mobile.
- Confirm PDF and DOCX resume downloads.
- Confirm GitHub and LinkedIn links.
- Keep MLB EDGE labeled as an active build until its repo is published/audited.
- Keep concept graphics labeled illustrative until replaced with evidence screenshots.
- Add real AIOS Command Center screenshots when ready.
